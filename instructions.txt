This describes how you use tmux-injector tools. This is how the system works.

==========
1. TOOL SELECTION
==========

┌─ Start interpreter (python3, openroad, etc.)
│   └─→ xsh_peek / xpy_peek / xtcl_peek
│       (no end marker, wait=1~2 seconds)
│
├─ Run short command (wait for completion)
│   └─→ xsh / xpy / xtcl (blocking)
│
├─ Run long task (need monitoring)
│   └─→ xsh_start / xpy_start / xtcl_start (non-blocking)
│       then task_status / task_output / task_wait
│
├─ Respond to prompt (password, yes/no)
│   └─→ send_text
│
└─ Check current screen
    └─→ capture_pane

==========
2. COMMON PATTERNS
==========

Starting an interpreter and running code:
    xsh_peek(pane, "python3", wait=1)      # start interpreter
    xpy(pane, "print('hello')")            # run code (blocking)
    xpy_peek(pane, "exit()", wait=1)       # exit interpreter

Starting a long-running script (with monitoring):
    xsh_peek(pane, "python3", wait=1)      # start interpreter
    xpy_start(pane, file="train.py")       # returns task_id
    task_status(task_id)                   # quick status check
    task_output(task_id, tail=10)          # last 10 lines
    task_wait(task_id, timeout=300)        # block until complete

Waiting for multiple tasks:
    tid1 = xsh_start(pane1, "make build")
    tid2 = xsh_start(pane2, "make test")
    task_wait(task_ids=[tid1, tid2], timeout=300)

Race mode (return on first completion):
    task_wait(task_ids=[tid1, tid2, tid3], race=True, timeout=600)

Without monitoring (no task_id):
    xsh_peek(pane, "python3 train.py", wait=2)
    capture_pane(pane, tail=30)

SSH connection:
    xsh_peek(pane, "ssh user@host", wait=2)
    send_text(pane, "password")
    capture_pane(pane)
    xsh(pane, "hostname")
    xsh_peek(pane, "exit", wait=1)

Passing variables from REPL to script (globals trick):
    xpy(pane, "model_path = '/path/to/model'")
    xpy_start(pane, file="train.py")       # script accesses via globals().get('model_path', None)
    # file= uses exec() which shares REPL's globals()

==========
3. PANE REGISTRATION (REQUIRED)
==========

Panes must be registered before use.

    set_working_pane("t1:1.0", "description")
    get_working_panes()

"Pane not registered" error → get_working_panes() first, then re-register if needed.

==========
4. CODE LIMITATIONS
==========

Literal \n in code breaks tmux injection (\n becomes Enter key).
    Forbidden: xpy(pane, "result.split('\n')")
    Use: splitlines(), chr(10), print()

All tools use exec(). Bare expressions produce no output. file= also uses exec().
    xpy(pane, "x") → empty. Use print(x).

Do not use import/reload in REPL. Use file= instead.
    xpy(pane, file="/path/to/module.py")

Compound statements (for/if/while/def/class/with/try) require triple-quoted strings.
Semicolons work only for simple statements.
    xpy(pane, """
    for x in range(10):
        print(x)
    """)

==========
5. FILE SAVE WORKFLOW
==========

task_output supports saving to file. Verify output before saving:

    task_id = xtcl_start(pane, "report_timing")
    task_wait(task_id)
    task_output(task_id)                                    # verify
    task_output(task_id, save="/tmp/report.md", append=True,
                include_command=True, markdown=True,
                prefix="## Timing\n\n", suffix="\n\n")

markdown=True auto-wraps in code fences with lang from task type.

==========
6. STATE TRACKING
==========

Pane state is tracked in memory. capture_pane is not called before every command.

State changes to remember:
- xsh_peek(pane, "python3") → pane is now Python REPL (>>>)
- xpy_peek(pane, "exit()") → pane is now bash ($)
- xsh_peek(pane, "openroad") → pane is now TCL (%)
- xtcl_peek(pane, "exit") → pane is now bash ($)
- send_keys("C-c C-c") → uncertain, capture_pane to confirm

capture_pane is used when:
- First time accessing a pane in this conversation
- After Ctrl+C interrupt (state uncertain)
- After abort/timeout from blocking tools (use task_list to find converted task)

==========
7. ABORT/TIMEOUT BEHAVIOR
==========

Abort/timeout means "end marker not received", not "command not sent".
The command was already sent to tmux. Do not resend.

Blocking tools auto-convert to background task on timeout or cancellation.
After abort/timeout: task_list() to find the converted task, then task_wait/task_output.

Exit commands produce no end marker. Use peek for exit:
    xtcl_peek(pane, "exit", wait=1)

==========
8. CONVERSATION CONTINUITY
==========

Registered panes persist in MCP server memory across conversation compaction.
After compaction: get_working_panes() to check what is registered.
New session or server restart: ask user which pane to use.
